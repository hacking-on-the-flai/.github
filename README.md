## 🎯 Why we're here

- 🛠️ Build weird, wonderful, and maybe-questionably-stable prototypes
- ☕ Turn coffee into features
- 🤖 Push the boundaries of what AI can do (and what it probably shouldn't)
- 🧪 Prove that "it works on my machine" is a valid debugging methodology (temporarily)

## 📏 Ground rules (unofficial but emotionally true)

| Rule | Consequence |
|------|-------------|
| If your demo needs `--force` | It's still a demo ✅ |
| If it trains a model | +10 wizard points 🧙 |
| If it works first try | Check for hidden bugs — that's suspicious 🕵️ |
| If you prompt-engineer your way out | That counts as coding 💯 |
